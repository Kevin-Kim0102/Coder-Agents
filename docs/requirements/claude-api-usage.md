# Claude API 额度

用户要求：额度跟随 Claude CLI 当前模型请求地址，不固定域名；显示已用 / 上限、可用的重置倒计时、更新时间和刷新。输入区移除读取模型按钮，设置页保留。

方案：复用 Claude 配置解析，按项目 cwd 和认证指纹隔离缓存，主动查询同一 API 前缀下的 GET /v1/usage（Sub2API 协议）。不支持的服务明确提示；不猜余额接口，不跨域转发凭据。普通页面轮询只读缓存。

字段：订阅优先每日，其次每周/月；限额型使用 quota；只有余额时显示余额。单位使用协议 unit 的受限映射。明确返回带时区的 reset_at 才显示“几h 几m 后重置”；缺失时显示“重置时间未知”，时间到后显示“等待重置”，expires_at 是到期而不是重置。保留旧数据仅限同一认证指纹；失败只显示安全错误。

验证：动态地址与 /v1 前缀、认证头、订阅/限额/余额、无重置时间、无效字段、重定向和错误脱敏、缓存隔离和刷新限频、项目范围、DOM 格式与按钮移除。

完成验证：188 项后端测试、39 项 DOM 检查通过；本机页面成功从当前生效 API 查询每日额度，未发起模型推理。
